# Security policy

## Reporting a vulnerability

Please report security issues privately, not in public issues:

- **GitHub:** use [Report a vulnerability](https://github.com/proxy302/proxy302-mcp/security/advisories/new) (private advisory), or
- **Email:** partners@proxy302.com with the subject "Security".

We reply within 3 working days and keep you updated until the fix ships. Please give us reasonable time to fix the issue before disclosing it.

## Scope

- This repository (the local `proxy302-mcp` server).
- The hosted MCP endpoints `https://mcp.proxy302.com/mcp` and `https://proxy302.com/v1/mcp`, including the sign-in (OAuth) pages on `mcp.proxy302.com`.

Never include real API keys or proxy passwords in a report; a redacted value is enough.
